BDF portable mode

While this file sits next to bdf.exe, BDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the BDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move BDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\BDF and
%LOCALAPPDATA%\BDF) instead. If BDFData can't be written (for example on a read-only
drive), BDF says so and uses the per-user folders instead.
