# BDF branding: storage, identity and what still carries an inherited name

Status: implemented for BUILD-015 (2026-11-04); local checks only until hosted CI and Codex review report. Owner
assignment: [bdf-branding-build-spec.md](bdf-branding-build-spec.md).

## What BDF presents as its own

| Surface | BDF identity |
|---|---|
| Executables | `bdf.exe` (the one launcher), `bdf-cli.exe`, `bdf-worker.exe`; Windows version properties name product BDF, original file name and internal name per executable |
| Window, Home, About, menus, dialogs, notifications, translations, CLI help/version, MCP `serverInfo`, MCP resource URIs (`bdf://…`) | BDF |
| Links | project and Help: `https://github.com/btecme/bdf`, issues: `…/issues`, update check: `https://api.github.com/repos/btecme/bdf/releases/latest`; no Discord, community or website entry; a repository with no release answers "no BDF release has been published yet", and only a page under `…/btecme/bdf/releases` is ever offered |
| Windows installer | MSI product BDF, install folder `Program Files\BDF`, new UpgradeCode `{0F334A01-A3CE-43E4-8E43-21EA4C6DCD17}` (generated for BDF, never to change; the upstream code is asserted absent by `test-msi.ps1`), new component GUIDs, `HKLM\Software\BDF\Capabilities`, `BDF.Document`, `Applications\bdf.exe`, App Paths `bdf.exe`; BDF is offered under "Open with"/Default apps and never made the default handler; publisher "BDF project" |
| Artwork | generic contributor-original app icon and PDF-document icon (`assets/app-icon/`, generated by `packaging/icons.py`); `docs/brand/` (the ArtCraft marks' licence) removed |
| Generated PDFs | `Producer` of a document BDF *creates* is BDF; the metadata and content of a document the person opens are never rewritten |

## Storage

| What | Installed | Portable (`portable.txt` or `BDF.portable` beside `bdf.exe`) |
|---|---|---|
| Settings (`app.ron`), logs (`logs\bdf.log`, `bdf.1.log`, `bdf.2.log`) | `%APPDATA%\BDF\data` (eframe's per-user data folder) | `BDFData\` beside the executable |
| Crash recovery | `%LOCALAPPDATA%\BDF\Recovery` | `BDFData\Recovery` |
| Clipboard images | `%LOCALAPPDATA%\BDF\Clipboard` | `BDFData\` |
| New digital IDs | next to the recovery folder (`…\BDF\Digital IDs`) | `BDFData\Digital IDs` |
| Single-instance hand-off (a socket and a lock file) | `%LOCALAPPDATA%\BDF\instance.*` | `%LOCALAPPDATA%\BDF\portable-instance.*`, so a portable copy never hands files to an installed one; the only write a portable copy makes outside `BDFData` |
| Agent grants and audit | `bdf-cli grant … --state-dir` (explicit; unchanged) | same |

BDF never reads, moves, imports or deletes the data of an installed or portable PdfCraft: not its settings, not its
recovery files, and never its grants or credentials. The migration of the former PrintCraft folders that PdfCraft
carried was removed with the rename (it would have moved another product's folder). Upstream data stays exactly where
it was.

**Old preview data.** The earlier local preview (`target/bdf-preview-aee35194`, `pdfcraft.exe`) keeps its settings
and autosaves in its own `PdfCraftData\` folder beside that executable. Nothing deletes it. Unsaved work from that
preview is recovered by starting that preview's `pdfcraft.exe` once (its Recovery dialog offers it), saving the
document, and opening the saved file in BDF. BDF has no import path from it by design.

## What still carries an inherited name, and why

| Where | Name | Role |
|---|---|---|
| `LICENSE-MIT`, `NOTICE`, `README.md` origin paragraph, `ATTRIBUTION.*`, `contributors/`, About credit line "Based on PdfCraft by the ArtCraft team.", Windows `LegalCopyright`, `assets/app-icon/LICENSE*.txt` | PdfCraft, ArtCraft Team | required copyright, licence and contributor acknowledgement; legal names are kept |
| `docs/bdf-evidence/`, `docs/adr/`, `docs/bdf-*.md` specifications and reviews, `ROADMAP.md` progress log, upstream issue links in `docs/gaps.md` and `docs/target-app-parity.md` | PdfCraft | historical records and accurate references to the upstream repository |
| `vendor/**` ("PdfCraft patch" comments), `craft-fonts`, `craft-libs`, WordCraft/VectorCraft/PhotoCraft mentions in comments | Craft family | third-party or sibling-project source and dependencies; not edited |
| Cargo package, crate and directory names (`pdfcraft-*`, `apps/pdfcraft*`), the Rust type `PdfCraftApp`, `cargo -p pdfcraft` | pdfcraft | internal technical names (blanket renaming is out of scope); the executables they build are `bdf*.exe` |
| Environment variables `PDFCRAFT_*` (renderer, title bar, build label, system fonts, winres, version) | PDFCRAFT | build/diagnostic knobs, not identity. `PDFCRAFT_MODELS` became `BDF_MODELS` because the error text tells a person to set it |
| Log filter prefix `pdfcraft*`, `pdfcraft:` target prefix in `bdf.log` lines | pdfcraft | crate-name based `RUST_LOG` targets |
| Hidden temporary names `.<name>.pdfcraft-tmp`, `.<name>.pdfcraft-<hex>.tmp` | pdfcraft | atomic-save staging files; stale ones are recognised by this pattern, tests plant it |
| Linux/FreeBSD/macOS/Flatpak application id `ai.storyteller.pdfcraft`, the packaged icon theme name, desktop/mime/metainfo file names, `share/pdfcraft/models`, `pdfcraft-<v>-<platform>` artifact names | pdfcraft, storyteller | non-Windows packaging: binaries and visible names follow BDF, identifiers are internal and were not re-registered; this packaging is unchanged in behaviour and **not exercised** in this delivery |
| `assets/demo/` (showcase PDF source), `docs/images/pdfcraft-*.png` and their entries | PdfCraft | demonstration content and screenshots of the inherited UI; to be replaced by `cargo xtask screenshots` runs |
| Translation values for languages that inflect a name (`BDFu`, `BDFban`, …) | — | the name was replaced mechanically; grammar of 22 catalogues is unreviewed |
| `xtask/src/assets.rs` brand-licence allowance | `LicenseRef-Storyteller-Trademark` | code that now matches no asset; kept so a future accidental re-addition fails loudly |
| Test fixtures, `pdfcraft.dev` and `pdfcraft-test.invalid` sample URLs, temp folder prefixes | pdfcraft | test data only |
